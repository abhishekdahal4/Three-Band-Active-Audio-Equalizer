# Three-Band-Active-Audio-Equalizer
An analog audio equalizer designed using LM741 operational amplifiers and active RC filters. The circuit separates an audio signal into low, mid, and high frequency bands, allowing independent adjustment before recombination.

Key specifications
Band	Frequency
Low	329 Hz cutoff
Mid	867 Hz peak response
High	2.19 kHz cutoff
